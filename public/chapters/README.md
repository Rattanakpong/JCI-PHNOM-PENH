# Chapter logos

Drop each chapter's logo in this folder using one of these exact filenames
(any of `.png`, `.jpg`, `.jpeg`, `.svg`, `.webp` works):

- `phnom-penh.png`
- `chaktomuk.png`
- `mekong.png`
- `toul-kork.png`
- `chbar-ampov.png`
- `siem-reap.png`
- `neak-poan.png`

The JCI Cambodia page (`/about/jci-cambodia`) picks up each file automatically
on the next request — no code changes needed. Chapters without a matching
file keep showing a placeholder tile.
